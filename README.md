# Omnia releases

Installers for **Omnia**, an infinite canvas of terminals and AI agents.

Download the latest version from [Releases](https://github.com/lketerson/omnia-releases/releases/latest) or visit **https://omnia.lketerson.com**.

Each release ships `SHA256SUMS.txt` so you can verify the files you downloaded.

This repository holds only the installers; the source code is not public.
